Product roadmaps you can edit visually or as JSON

RoadScript is a roadmap tool for product owners and the stakeholders they keep informed. Build a roadmap by clicking, or write it as JSON. It saves to this browser, so there is no account and nothing to install.

See an example roadmap

The example is a real roadmap: my own project history, built in RoadScript.

Swipe sideways to see the whole timeline, or open it to read each item.

Two ways to edit one roadmap

Both views edit the same data, so a change in one shows up in the other.

Visual editor

For stakeholders

Click any lane, column, item or milestone to change it. Good for quick updates and for walking someone through the plan.

JSON editor

For technical users

Every roadmap is plain JSON. Paste one in, bulk-edit items, or keep it in version control next to your code.

  "title": "RoadScript",
  "start": 4.6,
  "length": 2.1,

  "description": "- Visual editor for stakeholders"
}

Why I built this

A Fortune 500 bank client asked for roadmaps of our development work during an onsite visit. I had the first version of RoadScript live within a week, then kept refining it through daily use at work.

The examples include RoadScript's own build history, taken from its git log.

I build with AI coding agents. I write the plan, the agents implement it, and I review and merge every change.
